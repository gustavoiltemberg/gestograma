# 📅 Gestograma Digital

Um gestograma digital interativo e responsivo, criado para auxiliar no cálculo da idade gestacional e da Data Provável do Parto (DPP) a partir da Data da Última Menstruação (DUM). 

O projeto simula a experiência física de um gestograma de papel/plástico, mas com a facilidade e precisão do ambiente digital.

## ✨ Funcionalidades

*   **Cálculo Automático:** Idade gestacional em semanas e dias, e DPP calculada com base na regra de Naegele (280 dias).
*   **Roda Interativa:** Arraste com o mouse (ou dedo no celular) para girar a roda e atualizar a data.
*   **Limites de Segurança:** A roda inteligentemente impede que a DUM seja uma data futura ou que passe de 42 semanas de gestação.
*   **Calendário Integrado:** Selecione a data diretamente pelo calendário (Flatpickr) com restrições automáticas de data.
*   **Marcador de Hoje:** Um ponteiro fixo que indica a posição da data atual no anel, atualizando-se sozinho na virada da meia-noite.

## 🛠️ Tecnologias Utilizadas

*   **HTML5 & CSS3:** Estrutura e estilização, com design limpo e focado na usabilidade.
*   **JavaScript (Vanilla):** Toda a lógica matemática, controle de eventos de arraste, limites de data e manipulação do DOM.
*   **Flatpickr:** Biblioteca leve para o seletor de datas.

## 🚀 Como Executar o Projeto

Como o projeto é 100% frontend (não possui backend), você pode executá-lo de duas formas:

1.  **Direto no navegador:** Basta baixar ou clonar o repositório e dar um duplo clique no arquivo `index.html`.
2.  **Pelo GitHub Pages:** (Se você ativou o Pages) Acesse o link ao vivo: `https://gustavoiltemberg.github.io/gestograma/`

## ⚠️ Aviso Importante

Este projeto foi desenvolvido com fins educacionais e de apoio informativo. **Ele não substitui, de forma alguma, a avaliação de um médico ou obstetra.** A idade gestacional e a DPP devem sempre ser confirmadas por um profissional de saúde, especialmente com o auxílio de ultrassonografias.
